=====================
Plymouth SUPERHOT Theme
=====================

A very simple boot animation that displays the SUPERHOT loading screen.

Dependencies:

* Plymouth

Installation
------------

Download the source from https://github.com/m0tholith/plymouth-superhot-theme and
install the files to ``/usr/share/plymouth/themes/supergot``.

Usage
-----

Plymouth is required, so install it first.
Set the plymouth theme::

  plymouth-set-default-theme superhot
